# DailyTick - Habit Tracker & Daily Log

Una aplicación web FullStack moderna para seguimiento de hábitos con gamificación.

## 🚀 Características

- Gestión de hábitos personalizada con emojis y frecuencias
- Estadísticas en tiempo real con gráficos
- Calendario interactivo mensual
- Sistema de gamificación con 10 logros desbloqueables
- Temas claro y oscuro
- Diseño responsive

## 🛠️ Tech Stack

- Frontend: HTML5, Tailwind CSS, JavaScript Vanilla
- Backend: Node.js, Express.js
- Base de datos: MongoDB Atlas con Mongoose

## � Instalación

```bash
npm install
```

## 🚀 Ejecución

```bash
npm start
```

La aplicación estará disponible en http://localhost:3000

## 🔐 Variables de Entorno

- `MONGODB_URI`: URL de conexión a MongoDB Atlas
- `PORT`: Puerto del servidor (default: 3000)
- `SESSION_SECRET`: Secreto para sesiones
- `JWT_SECRET`: Secreto para tokens JWT
- `NODE_ENV`: Entorno (development/production)
